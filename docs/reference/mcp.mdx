Notare exposes an embedded Model Context Protocol (MCP) server accessible via HTTP streamable transport (`http://127.0.0.1:<port>`) with Bearer token authentication, or via the `notare-mcp` stdio bridge.

Every tool is read-only, non-destructive, and local-only.

For client configuration recipes and transport details, see [MCP for agents](/agents/mcp) and the [MCP Server Guide](../MCP.md).

## Available tools

### `list_meetings`

List recent meetings with pagination and optional filtering.

| Parameter | Type | Default | Notes |
|---|---|---|---|
| `query` | string | `null` | Case-insensitive title or meeting ID substring. |
| `limit` | integer | `20` | Maximum number of meetings to return. |
| `offset` | integer | `0` | Number of records to skip. |

### `get_meeting`

Retrieve full meeting details for a specific session.

| Parameter | Type | Default | Notes |
|---|---|---|---|
| `id` | string | required | The unique meeting/session ID. |

Returns meeting metadata, note content, generated summaries, participants, and action items.

### `get_meeting_transcript`

Fetch transcript text and word-level timestamps.

| Parameter | Type | Default | Notes |
|---|---|---|---|
| `id` | string | required | The unique meeting/session ID. |
| `offset` | integer | `0` | Word offset for pagination. |
| `limit` | integer | `200` | Maximum number of words to return. |

### `search_meetings`

Search meetings using Notare's on-device Tantivy full-text index.

| Parameter | Type | Default | Notes |
|---|---|---|---|
| `query` | string | required | Search query string. |
| `limit` | integer | `20` | Maximum results to return. |
| `offset` | integer | `0` | Result pagination offset. |

### `search_meeting_content`

Perform lexical keyword search across meeting notes and transcript text.

| Parameter | Type | Default | Notes |
|---|---|---|---|
| `query` | string | required | Keyword or exact phrase to find. |
| `meeting_ids` | string[] | `null` | Optional list of specific meeting IDs to restrict search to. |
| `limit` | integer | `20` | Maximum matches to return. |

### `list_recipes`

List all available AI prompt recipes configured in Notare. Takes no parameters.

### `get_daily_note`

Retrieve the daily note for a specific date.

| Parameter | Type | Default | Notes |
|---|---|---|---|
| `date` | string | required | Date string formatted as `YYYY-MM-DD`. |
