0.6.0 was tested as release candidates only; its features shipped to everyone in 0.6.4.

## Local AI

- Chat, summaries and action items can run entirely on your device with Qwen3 4B, Llama 3.1 8B, Phi-4 Mini, Mistral 7B or Gemma 3 4B
- Model files are verified before use; the first run downloads 2.5–5 GB
- Windows runs the model on the CPU, Linux uses Vulkan, and macOS has a Metal toggle in Settings → Intelligence

## Recording

- A redesigned recording bar shows a running timer and word count
- Dictation improvements

## Notes

- A trash view lets you restore or permanently delete notes
