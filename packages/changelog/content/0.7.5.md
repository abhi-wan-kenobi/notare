## Fixes

- Semantic search across your meetings now runs, including the embedding model download, indexing new meetings and the context chat looks up before it answers
- Meetings transcribed with a local model (Whisper or Parakeet) or your own speech-to-text server get "Speaker 1", "Speaker 2" labels
- Changing the language or participants while a meeting is recording now reaches the recorder
- The included-apps list for meeting detection takes effect
- "Show in file manager" on a Soniqo speech-to-text model opens its folder
- The GitHub issue view shows comments

## Transcription

- When Voxtral gets stuck repeating a short phrase until the end of a passage, the repeats are collapsed to one; a phrase repeated two or three times, or repetition followed by more speech, is kept as said

## Security

- Updated Rust and JavaScript dependencies to versions with published security fixes
