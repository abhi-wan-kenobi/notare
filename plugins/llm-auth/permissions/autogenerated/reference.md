## Default Permission

Default permissions for tauri-plugin-llm-auth

#### This default permission set includes the following:

- `allow-status`
- `allow-start`
- `allow-complete`
- `allow-cancel`
- `allow-logout`
- `allow-access-token`
- `allow-catalog`
